# Bean & Brew Coffee Shop Website

A responsive, multi-page website for a fictional coffee shop, "Bean & Brew".

## Features
- **Home**: Hero section, features, and call-to-action.
- **Menu**: Categorized menu with images and prices.
- **About Us**: Team section and company story.
- **Gallery**: Photo gallery of the shop and products.
- **Contact**: Contact form and location info.
- **Responsive Design**: Works on mobile, tablet, and desktop.

## Technologies Used
- HTML5
- CSS3 (Custom properties, Flexbox, Grid)
- JavaScript (Mobile menu toggle, Tab filtering)

## Deployment
This project is ready for deployment on Netlify.

### How to Deploy
1.  **Push to GitHub**: Ensure your latest changes are pushed to your GitHub repository.
2.  **Log in to Netlify**: Go to [netlify.com](https://www.netlify.com/) and log in (you can use your GitHub account).
3.  **New Site from Git**: Click "Add new site" > "Import an existing project".
4.  **Connect GitHub**: Select GitHub and authorize Netlify.
5.  **Select Repository**: Choose this repository from the list.
6.  **Deploy**: The build settings should be automatically detected (Publish directory: `.`). Click "Deploy site".

Your site will be live in seconds!
